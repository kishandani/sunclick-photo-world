# Sunclick Photo World

A responsive photography studio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure and image URLs
- `css/style.css` — responsive styling and layout
- `js/script.js` — mobile menu, portfolio filters, and WhatsApp enquiry form
- `images/` — add your own licensed photography assets here

## Run locally
Open `index.html` in a browser. For a smoother development workflow, use VS Code with the Live Server extension.

## Before publishing
1. In `js/script.js`, replace `91XXXXXXXXXX` with your WhatsApp number including country code, digits only.
2. Update the placeholder phone, email, and city in `index.html`.
3. Replace the sample photographer names and portraits with your actual team.
4. Replace sample Unsplash image URLs with your own licensed images if desired.
5. Deploy the folder to a static host such as GitHub Pages, Netlify, or your web hosting provider.

The enquiry form opens WhatsApp with a pre-filled message; it does not store enquiries in a database.
